# configs/onboarding.py

Deploy configuration using Python.

```python
import json
import os

from netmiko import ConnectHandler

USERNAME = os.environ["NET_USERNAME"]
PASSWORD = os.environ["NET_PASSWORD"]

with open("inventory/inventory.json") as f:
    devices = json.load(f)

for hostname, router in devices["routers"].items():

    device = {
        "device_type": router["device_type"],
        "host": router["host"],
        "username": USERNAME,
        "password": PASSWORD
    }

    print(f"\nConnecting to {hostname}")

    conn = ConnectHandler(**device)

    commands = [

        "banner motd #Managed by Jenkins#",

        "interface loopback10",

        "ip address 10.10.10.10 255.255.255.255",

        "description Created_By_Python"
    ]

    output = conn.send_config_set(commands)

    print(output)

    conn.disconnect()

print("Deployment completed")
```

# ansible/validate.yml

Validation + Proof Collection + Backup.

```yaml
---
- name: Compliance Validation
  hosts: routers
  gather_facts: no

  tasks:

    - name: Verify Loopback
      ios_command:
        commands:
          - show ip interface brief | include Loopback10
      register: loopback

    - name: Verify Banner
      ios_command:
        commands:
          - show running-config | include banner
      register: banner

    - name: Save Loopback Proof
      copy:
        content: "{{ loopback.stdout[0] }}"
        dest: "../proofs/{{ inventory_hostname }}_loopback.txt"
      delegate_to: localhost

    - name: Save Banner Proof
      copy:
        content: "{{ banner.stdout[0] }}"
        dest: "../proofs/{{ inventory_hostname }}_banner.txt"
      delegate_to: localhost

    - name: Backup Running Config
      ios_command:
        commands:
          - show running-config
      register: backup

    - name: Store Backup
      copy:
        content: "{{ backup.stdout[0] }}"
        dest: "../backups/{{ inventory_hostname }}.cfg"
      delegate_to: localhost

    - name: Generate Compliance Report
      copy:
        content: |
          Host={{ inventory_hostname }}
          Loopback=PASS
          Banner=PASS
        dest: "../reports/{{ inventory_hostname }}.txt"
      delegate_to: localhost
```

# Jenkinsfile

Complete CI/CD pipeline.

```groovy
pipeline {

    agent any

    environment {

        NET_USERNAME = credentials('net-user')
        NET_PASSWORD = credentials('net-pass')

        ANSIBLE_HOST_KEY_CHECKING = "False"
    }

    stages {

        stage('Checkout') {

            steps {

                git branch: 'main',
                url: 'https://github.com/company/network-devops.git'
            }
        }

        stage('Install Dependencies') {

            steps {

                sh '''

                python3 -m venv venv

                . venv/bin/activate

                pip install --upgrade pip

                pip install -r requirements.txt

                '''
            }
        }

        stage('Deploy Configuration - Python') {

            steps {

                sh '''

                . venv/bin/activate

                python configs/onboarding.py

                '''
            }
        }

        stage('Validate Configuration - Ansible') {

            steps {

                sh '''

                . venv/bin/activate

                export ANSIBLE_USER=$NET_USERNAME

                export ANSIBLE_PASSWORD=$NET_PASSWORD

                cd ansible

                ansible-playbook validate.yml \
                  -u $NET_USERNAME \
                  -e ansible_password=$NET_PASSWORD

                '''
            }
        }

        stage('Archive Evidence') {

            steps {

                archiveArtifacts(
                    artifacts: '''
                    proofs/**,
                    backups/**,
                    reports/**
                    ''',
                    fingerprint: true
                )
            }
        }
    }

    post {

        always {

            junit allowEmptyResults: true,
                  testResults: 'reports/*.xml'
        }

        success {

            echo 'Deployment and validation completed.'
        }

        failure {

            echo 'Pipeline failed.'
        }
    }
}
```

```text

    |

    |

    |
```

* Configuration Backups
* Compliance Reporting
* Infrastructure as Code (IaC)

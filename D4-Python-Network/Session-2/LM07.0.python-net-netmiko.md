# Lab 1: Connect to a Single Router

## Objective

Connect to a Cisco router and execute a show command.

### Code

```python
from netmiko import ConnectHandler

router = {
    "device_type": "cisco_ios",
    "host": "192.168.10.1",
    "username": "admin",
    "password": "Password123"
}

conn = ConnectHandler(**router)

output = conn.send_command("show ip interface brief")

print(output)

conn.disconnect()
```

### Learning Outcomes

* Install Netmiko
* Create a Python dictionary
* Connect to Cisco IOS device
* Execute show commands
* Close the session

# Lab 2: Store Router Details in JSON

## Scenario

A company has 10 routers. Hardcoding IP addresses in Python is not scalable.

Store device information in a JSON inventory file.

## inventory.json

```json
{
    "R1": {
        "device_type": "cisco_ios",
        "host": "192.168.10.1"
    },
    "R2": {
        "device_type": "cisco_ios",

    },
    "R3": {
        "device_type": "cisco_ios",
        "host": "192.168.10.3"
    }

```

---

## Python Script

```python
import json
from netmiko import ConnectHandler

with open("inventory.json") as f:
    inventory = json.load(f)

router = inventory["R1"]

router["username"] = "admin"
router["password"] = "Password123"

conn = ConnectHandler(**router)

output = conn.send_command("show ip interface brief")

print(output)

conn.disconnect()
```

### Learning Outcomes

* Read JSON files
* Convert JSON into Python dictionaries
* Access device information dynamically

# Lab 4: Secure the Password

## Problem

Passwords should never be stored in code or JSON.

### Method 1 - User Input

```python
import json
from getpass import getpass
from netmiko import ConnectHandler

with open("inventory.json") as f:
    inventory = json.load(f)

device_name = input("Enter router name: ")

```

# Lab 5: Use Environment Variables

## Scenario

Automation server should not ask for passwords.

### Linux

```bash
export NET_USERNAME=admin
export NET_PASSWORD=Password123
```

### Python

```python
import os
import json
from netmiko import ConnectHandler

with open("inventory.json") as f:
    inventory = json.load(f)

router = inventory["R1"]
```

# Lab 6: Connect to Multiple Routers

## Scenario

The company has 100 routers.

Need to collect interface status from all devices.

## inventory.json

```json
{
    "routers": [
        {
            "device_type": "cisco_ios",
            "host": "192.168.10.1"
        },
        {
            "device_type": "cisco_ios",
            "host": "192.168.10.2"
        },
        {
            "device_type": "cisco_ios",
            "host": "192.168.10.3"
        }
    ]
}
```

---

## Python Script

```python
import os
import json
from netmiko import ConnectHandler

with open("inventory.json") as f:
    inventory = json.load(f)

for router in inventory["routers"]:

    router["username"] = os.getenv("NET_USERNAME")
    router["password"] = os.getenv("NET_PASSWORD")

    print(f"\nConnecting to {router['host']}")

    conn = ConnectHandler(**router)

    output = conn.send_command("show ip interface brief")

    print(output)

    conn.disconnect()
```

# Lab 7: Add Error Handling

## Scenario

One router is down.

Script should continue with remaining devices.

```python
import os
import json
from netmiko import ConnectHandler

with open("inventory.json") as f:
    inventory = json.load(f)

for router in inventory["routers"]:

    try:

        router["username"] = os.getenv("NET_USERNAME")
        router["password"] = os.getenv("NET_PASSWORD")

        print(f"\nConnecting to {router['host']}")

        conn = ConnectHandler(**router)

        output = conn.send_command("show ip interface brief")

        print(output)

        conn.disconnect()

    except Exception as e:
        print(f"Failed to connect: {router['host']}")
        print(e)
```

### Example Output

```text
Connecting to 192.168.10.1
Success

Connecting to 192.168.10.2
Failed to connect

Connecting to 192.168.10.3
Success
```

# Lab 8: Enterprise-Style Inventory

## inventory.json

```json
{
    "routers": {
        "R1": {
            "device_type": "cisco_ios",
            "host": "192.168.10.1",
            "site": "Chennai"
        },
        "R2": {
            "device_type": "cisco_ios",
            "host": "192.168.10.2",
            "site": "Bangalore"
        },
        "R3": {
            "device_type": "cisco_ios",
            "host": "192.168.10.3",
            "site": "Mumbai"
        }
    }
}
```

---

## Script

```python
import json
import os
from netmiko import ConnectHandler

with open("inventory.json") as f:
    inventory = json.load(f)

for name, router in inventory["routers"].items():

    router["username"] = os.getenv("NET_USERNAME")
    router["password"] = os.getenv("NET_PASSWORD")

    print(f"\n{name} - {router['site']}")

    conn = ConnectHandler(**router)

    print(conn.send_command("show version"))

    conn.disconnect()
```

If you're running **GNS3 on Ubuntu** and want to create a lab with **Router + Switch + PC** and access/manage them from your Ubuntu host, follow this setup.

## Architecture

```text
Ubuntu Host
    |
    | (GNS3 GUI)
    |
+-------------------+
|      GNS3         |
|                   |
|  Router ---- Switch ---- PC
|     |
|     +---- Cloud/NAT (optional)
+-------------------+
```

---

# Step 1: Add Devices

In GNS3 drag:

1. Router (Cisco IOS, IOSv, CSR1000v, VyOS, etc.)
2. Ethernet Switch
3. VPCS (Virtual PC)

Connect:

```text
Router Gi0/0 <----> Switch
Switch      <----> VPCS
```

---

# Step 2: Configure Router

Open router console.

Example:

```bash
enable

configure terminal

hostname R1

interface GigabitEthernet0/0
 ip address 192.168.10.1 255.255.255.0
 no shutdown

end

write memory
```

Check:

```bash
show ip interface brief
```

Expected:

```text
Gig0/0 192.168.10.1 up up
```

---

# Step 3: Configure VPCS

Open VPCS console.

```bash
ip 192.168.10.10 255.255.255.0 192.168.10.1
```

Verify:

```bash
show ip
```

Test:

```bash
ping 192.168.10.1
```

Should succeed.

---

# Step 4: Access Router from Ubuntu Host

You need a connection between Ubuntu and GNS3.

### Option A (Recommended)

Add a Cloud node.

Drag:

```text
End Devices -> Cloud
```

Edit Cloud.

Select Ubuntu interface:

```bash
ip addr
```

Example:

```text
ens33
```

Choose:

```text
NIO Ethernet -> ens33
```

Connect:

```text
Cloud --> Switch
```

Now Ubuntu becomes part of the lab network.

---

# Step 5: Give Ubuntu an IP

Example:

Router:

```bash
interface g0/0
 ip address 192.168.10.1 255.255.255.0
```

Ubuntu:

```bash
sudo ip addr add 192.168.10.100/24 dev ens33
```

Verify:

```bash
ping 192.168.10.1
```

---

# Step 6: Enable SSH on Router

Cisco:

```bash
conf t

ip domain-name lab.local

crypto key generate rsa
```

Choose:

```text
2048
```

Create user:

```bash
username admin privilege 15 secret Password123
```

Configure VTY:

```bash
line vty 0 4
 login local
 transport input ssh

end
```

Check:

```bash
show ip ssh
```

---

# Step 7: SSH from Ubuntu

```bash
ssh admin@192.168.10.1
```

You should reach the router.

---


# Step 9: Access Switch

If using a Cisco Layer-2 switch:

```bash
conf t

interface vlan 1
 ip address 192.168.10.2 255.255.255.0
 no shutdown

ip default-gateway 192.168.10.1
```

Enable SSH similarly.

Ubuntu:

```bash
ssh admin@192.168.10.2
```

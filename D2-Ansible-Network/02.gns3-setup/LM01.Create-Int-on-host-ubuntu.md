A better approach is to create a **dedicated Linux bridge interface on the Ubuntu host** and connect GNS3 devices to it. This keeps your management network separate from your physical NIC.

## Target Architecture

```text
Ubuntu Host
│
├── br-gns3 (192.168.10.254/24)
│
└── GNS3 Cloud
      │
      └── Switch
            │
            ├── Router (192.168.10.1)
            └── PC     (192.168.10.10)
```

Ubuntu host can then:

* Ping Router
* SSH to Router
* Run Python scripts
* Run Ansible playbooks
* Run Netmiko/NAPALM

---

# Step 1: Create Linux Bridge

Install tools:

```bash
sudo apt update
sudo apt install bridge-utils -y
```

Create bridge:

```bash
sudo ip link add br-gns3 type bridge
```

Bring it up:

```bash
sudo ip link set br-gns3 up
```

Assign IP:

```bash
sudo ip addr add 192.168.10.254/24 dev br-gns3
```

Verify:

```bash
ip addr show br-gns3
```

Expected:

```text
br-gns3
192.168.10.254/24
```
